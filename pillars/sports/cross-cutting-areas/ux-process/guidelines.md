## Overview

The Sports UX Process defines the end-to-end workflow that Sports pillar designers follow when delivering features. It is a sequential process with seven distinct phases, each with clear responsibilities and outputs. The process ensures consistency, quality, and collaboration across the Sports UX team.

Source: [Figma — Sports UX Process](https://www.figma.com/design/TWgYH9fRd3ehuJRSvFtvoL/Sports-UX-Process?node-id=1-30)

## Process Phases

### 1. Discovery

The initial phase where the team understands the problem space, stakeholder needs, and business context before diving into solutions.

### 2. Research

Where we evaluate competitors, gather relevant data and scrutinise similar existing features with users.

**Key activities:**
- Competitive analysis
- Gathering relevant data
- Evaluating similar existing features with users

### 3. UX Design

Where you dive deep, diverging through brainstorms and converging on the best one through design reviews and user testing.

**Key activities:**
- Divergent brainstorming
- Convergent decision-making through design reviews
- User testing to validate concepts

### 4. UI Design & Theming

Where you apply our design system to your feature, theme and hand off to tech.

**Key activities:**
- Applying the design system to the feature
- Theming for brand variants
- Developer hand-off

### 5. UAT (User Acceptance Testing)

Where you evaluate developers work and see if they meet our standards.

**Key activities:**
- Evaluating developer implementation
- Verifying design standards are met
- QA sign-off from UX perspective

### 6. Documentation / Library

Where you document the feature from UX perspective and submit new components to the library.

**Key activities:**
- Documenting the feature from a UX perspective
- Submitting new components to the design system library
- Updating pattern documentation

### 7. Post-Project

Where you keep a close eye on how our new feature is performing post launch.

**Key activities:**
- Monitoring feature performance post-launch
- Gathering post-launch metrics
- Identifying optimisation opportunities

## Principles in Context

The process is designed to:
- **Preserve speed for habitual workflows** while maintaining quality gates
- **Enable confidence-driven decisions** through research and testing at multiple stages
- **Ensure design system consistency** through the UI Design & Theming phase and Documentation phase
- **Support iterative improvement** through Post-Project monitoring
